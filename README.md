# RDR на 100%

Неофициальный трекер Red Dead Redemption (Steam-версия 2024 года, вместе с Undead Nightmare): 51 достижение по частям сюжета, испытания, 26 видов животных и карта с метками. Прогресс отмечается вручную, аккаунт Steam не нужен.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `RDR1-100-`.
2. На странице репозитория нажмите **uploading an existing file** (или Add file → Upload files).
3. Перетащите **содержимое** папки: `index.html`, `sw.js`, `manifest.webmanifest`, `favicon.svg`, `README.md` и папку `icons`. Папку `icons` именно перетаскивайте — через кнопку выбора файлов папки не загружаются.
4. Нажмите **Commit changes**.
5. **Settings → Pages**: Source — **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
6. Через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/RDR1-100-/`.

## Установить на телефон

- **Android (Chrome):** меню «⋮» → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке.

После первого открытия приложение работает и без интернета.

## Прогресс

Хранится в браузере на устройстве. Чтобы перенести его на другое устройство или из версии в Claude: внизу «Настройки → Перенос прогресса» → «Скопировать код», затем вставить код на другом устройстве.

## Как обновить

Замените файлы новыми и в `sw.js` поменяйте `rdr1-100-v1` на `rdr1-100-v2` (и так далее) — у пользователей обновление подтянется при следующем открытии с интернетом.

## Данные

Контуры Нью-Остина и Вест-Элизабет — из открытого проекта jeanropke/RDR2CollectorsMap (public domain); Мексика нарисована схематично. Гайды пересказаны по материалам PowerPyx, iRedDead и Gamepressure. Приложение не связано с Rockstar Games; Red Dead Redemption — их торговая марка.
